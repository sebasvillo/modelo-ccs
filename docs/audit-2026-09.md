# Code audit of the legacy notebook (September 2026)

Scope: `legacy/M9_Integracion.ipynb` (thesis model M9), read on 2026-09-30. Issues are listed by impact.
None of them is reported in the thesis document. Prototype and tower numbers must be treated as
**unreliable** until 1–4 are fixed. The economic conclusion (cell and electricity dominate the LCOC)
is robust, because it does not depend on the tower.

## 1. Dimensional inconsistency in the integration (critical)
The exponent uses `KGa [1/s] / G_molar [mol/s] · dz [m]`, which is not dimensionless. Correct form:
`KG·a·c_tot·A_col / G_molar · dz` (equivalently, molar flux G/A with c_tot = P/RT). At industrial flow
this is off by ~2–3 orders of magnitude, compensated by chance by issues 2 and 3. **This is why the
bench case always predicts ~100 % capture:** with G = 2.2e-3 mol/s the exponent is inflated (NTU 6–14).
The model–experiment mismatch in thesis Ch. 3 comes mainly from here, not only from extrapolated
correlations.

## 2. `A_ref = 1 m²` in `kL_kG_KGa`
Velocities used for Re and wetting are computed with a 1 m² reference area instead of the real column
area. Industrial case: computed uG = 53.8 m/s (real 3.9 m/s) → kG = 2.35 m/s (typical 0.001–0.05 m/s)
and KGa = 323 1/s (typical < 1 1/s). Thesis Sec. 2.6.1 states the real area is used: text and code
disagree.

## 3. Undocumented `liquid_resistance_factor = 0.001`
Shown as R_L in Eq. 2.24, but in code it is a tuning factor that divides the liquid-side resistance by
1000. It should be the dimensionless Henry constant (~1–2). It forces gas-side control and is the
**direct cause of the model not responding to NaOH concentration**. Quick check: with real areas and
factor = 0.001 the height is ~0.16 m; with factor = 1 it is ~46 m. The 15–16 m height is an artefact of
compensating errors.

## 4. No stoichiometric limit
Base case (1.5 M, L/G 0.005): the solvent brings 403 mol/s of OH⁻ and the tower "captures" 418 mol/s of
CO2. As carbonate, 2 OH⁻ per CO2 are needed (836 mol/s): **the Ch. 2 base case is chemically
impossible** (not even as bicarbonate). The final loading x exceeds ~2× the stoichiometric maximum.
Ha and E are computed once with fresh OH⁻ and never updated as hydroxide depletes. This explains why
the optimiser always prefers "high NaOH, minimum L/G": nothing penalises it.

## 5. Co-current, not counter-current
x = 0 is imposed at z = 0, where y = y_in (gas inlet) is also imposed. In counter-current flow the lean
solvent enters at the top: it is a boundary-value problem (shooting or solving both ends). Thesis
Fig. 2.3 describes counter-current; the code integrates co-current.

## 6. Cell: 1 electron per CO2
`E = F·V/tNa` assumes 1 e⁻/CO2 (bicarbonate route). If CO2 is captured as carbonate (as the thesis
chemistry and titration indicate), regenerating 2 NaOH requires moving 2 Na⁺ → **2 F per mol CO2**: cell
area and energy ~2×. Rough estimate: LCOC ~250 USD/t on grid power and ~45 USD/t with solar at
0.0182 USD/kWh. The qualitative conclusion holds, the figures do not. (Design alternative: load only to
bicarbonate to stay at 1 e⁻, at the cost of more solvent circulation.)

- Saved cell 1: H = 14.86 m, ΔP = 1919 Pa, blower 151.8 kW, pump 48.2 kW. Thesis Table 2.2: 16.36 m,
  2113 Pa, 167.1 kW, 51.2 kW (earlier code version).
- Cell 2 (`safe_design_from_previous_cells`) starts from `default_case` and **overwrites the global
  `Qg_Nm3h = 300 000`**, because `best` does not carry that key. Cells 10–12 (Ch. 4 optimisation) thus
  ran with twice the gas: G = 4107 mol/s, D = 5.84 m, optimum 4.37 M / L/G 0.0024, CAPEX 24.5 MUSD,
  OPEX 130.5 MUSD. Thesis Table 4.4 (4.12 m, 11.85 MUSD) comes from a different run. LCOC barely
  changes (125.8 vs 125.6) because electricity dominates.
- Cell 2 also merges dicts named `best`, `best_design`, `design`, `case` from `globals()`. The saved
  run started at In[91], so it inherited stale kernel state: its `P_total_W` was 66 977.8 kW, while
  cell 1 in the same run printed 66 959.4 kW. **From a clean kernel cell 2 gives LCOC 123.17, not the
  saved 123.20** (OPEX 64 893 539 vs 64 911 181 USD/yr). Found while building the golden master
  (phase 0); every other cell reproduces byte-for-byte.
- Cell 2 maps model outputs through an alias list that lacks `height_m`, so its TEA uses the
  default **H_packed = 25 m** instead of the 14.86 m computed by cell 1, and the default
  `pressure_bar = 1.01`. It also uses 44.0 g/mol for CO2 (cell 8 uses 44.01) and no cell, blower or
  pump CAPEX. Found while porting the TEA (phase 1).
- Cell 4 (`evaluate_integrated_design`, `sweep_design_space`, `refine_around_best`, dashboards) is
  dead code: it is only driven by cell 6, which fails. Cell 8 ("Intento 2") replaces it. Only
  `simulate_absorber_fixed_diameter` from cell 4 is used (bench, cell 17).
- `evaluate_design_point` freezes globals as default argument values at definition time → results
  depend on execution order.
- Cell 6 raises `KeyError: 'T_gas_abs_C'` (also in the saved run).
- Hours/year: cell 1 uses 8760 h and the TEA 8000 h; `kmol_s_from_Nm3h` uses 22.414 and the rest 44.615.
- `choose_best_design` does not filter designs that miss the capture target.
- Duplicated cells ("Intento 2"), `globals()` fallbacks, `print` inside loops (thousands of output lines).

## 8. Bench simulated with a different tower
Cell 17 uses `D_col_m = 0.0154` (15.4 mm; the real tower is 150 mm) and `pall_ring_25mm` instead of the
TPMS Schwarz-D. No effect on KGa (because of issue 2) but it affects ΔP.

## 9. Correlations cited more strongly than warranted
- Eq. 2.18 (Sh = 2 + 1.1 Re^n Sc^1/3) is Ranz–Marshall/Wakao type for particles, not Onda (Onda uses
  Re = L/(a·μ), (a·dp)^-2 and different coefficients).
- The exponential wetting (Eq. 2.19) is not Onda's correlation (which depends on σ, Fr, We, Re).
- Eqs. 2.13 and 2.15 are own closures, not Mazarei/Tamimi (those references only support D0).
- Ergun is for particle beds: for structured packings use Billet–Schultes or Rocha–Bravo–Fair.
- No E∞ (instantaneous-reaction) limit; acceptable in the base case because E∞ ≫ Ha at the inlet, but it
  must be enforced in general.

## 10. Minor technical items
- Pump head is 5 + 0.5·H m; it should be at least H plus losses.
- Zhang et al., *Nature Energy* vol. 10 corresponds to 2025, not 2023 (verify the reference).
